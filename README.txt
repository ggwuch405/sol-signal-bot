Как установить:
1. В GitHub открой репозиторий.
2. Открой каждый из пяти файлов и замени содержимое соответствующим файлом из архива.
3. Сделай Commit changes.
4. Подожди публикации GitHub Pages.
5. На телефоне открой сайт в Chrome и обнови страницу.

Важно:
- Если приложение уже установлено, закрой его полностью и открой снова.
- При старой версии кэша обновление может занять несколько минут.
- HYPEUSDT должен быть доступен в Bybit Spot API; если API вернёт ошибку по этой паре, она будет показана отдельно.
- Оценка строится по историческим данным и не предсказывает цену достоверно. Не используй её как единственное основание для финансовых решений.
- Никаких API-ключей или приватных данных в файлах нет.
