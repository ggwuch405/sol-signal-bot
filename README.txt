SOL SIGNAL — установка на GitHub Pages

1. Распакуйте архив.
2. Добавьте файлы index.html, app.js, manifest.webmanifest, sw.js и icon.svg в корень вашего GitHub-репозитория.
3. Сделайте Commit и Push через GitHub Desktop.
4. На GitHub откройте репозиторий → Settings → Pages.
5. В разделе Build and deployment выберите:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
   Нажмите Save.
6. Подождите публикацию. Адрес будет вида:
   https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/
7. Откройте ссылку в Chrome на Android → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

Примечания:
- В приложении нет ключей Bybit и Telegram.
- Запрашиваются только публичные рыночные данные Bybit Spot для SOLUSDT.
- Приложение загружает данные при открытии, обновляет каждые 30 секунд, пока вкладка видима, и позволяет обновить вручную.
- В фоне вычисления не идут. При повторном открытии выполняется новый запрос.
- Если браузер не сможет обратиться к Bybit API из-за сетевых ограничений/CORS, данные не загрузятся. В этом случае можно будет добавить бесплатный публичный прокси или иной источник, но не размещайте секретные ключи в браузерном коде.
